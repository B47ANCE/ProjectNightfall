## Current implementation

Project Nightfall owns sunlight hibernation, starvation-gated Feral conversion,
Smart and Alpha Feral policy, artificial-UV damage, effigy reactions, and Alpha
ecology. Project M.O.R.T.I.S. supplies identity, hunger observations, hierarchy,
memory, logical groups, and bounded runtime infrastructure. lightWorks supplies
emission facts; medWorks supplies severed-part provenance.

The Alpha ecology currently includes persistent hierarchy, rivalry, desertion,
Death Cry power vacuums, underground territories, distributed Smart dens,
light suppression, prey reports, probable-base evidence, artificial-UV emergency
displacement, pressure/season-gated physical migration initiation, and persisted
temporary daylight shelter objectives for multi-night journeys.

lightWorks 0.24 now exposes active dropped emitters through the real Build 42
physical thump contract. Existing den-defense and rare independent-attack policy
consume that provider without transferring zombie behavior into lightWorks.

The regional UV pipeline now owns configurable artificial-only canonical tissue
loss after real clothing transmission. An emitter-bounded, budgeted and fair
corpse runtime restores copied M.O.R.T.I.S. anatomy, avoids darkness backfill,
continues protected postmortem loss, and persists monotonic semantic remains
stages without replacing the corpse, changing its cause or clearing loot.

The requested artificial-UV tile-strength change is currently blocked by a
request/source mismatch: authoritative source already sums established
attenuated, obstruction-checked contributions at the target tile and feeds that
total directly into regional dose, while the referenced flat direct-damage path
exists only in stale staging backups. See
[the tile-strength handoff](ARTIFICIAL_UV_TILE_STRENGTH_HANDOFF.md) before making
any production change.
